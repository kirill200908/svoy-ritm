# Свой ритм

Личный трекер: десятки по математике и физике, другие десятки, задачи Codeforces и ejudge, контесты. Веса и ориентир редактируются; история и заметки сохраняются в браузере. Вкладка «Дневник» подключает Schools.by без аккаунта ChatGPT.

Сайт: [svoy-ritm.pprivetese788.workers.dev](https://svoy-ritm.pprivetese788.workers.dev/).

Подключение реальных оценок Schools.by пока проверяется: возможна ошибка распознавания страницы. Ручной ввод результатов работает независимо от подключения дневника.

Во вкладке «Дневник» есть кнопка «Проверить доступность Schools.by». Она проверяет связь сервера со страницей входа и сайтом школы, не используя логин, пароль или сохранённую сессию дневника.

## Размещение

GitHub хранит готовую сборку `index.mjs` и полный архив исходников `source.zip`. Cloudflare Workers публикует интерфейс и API на одном адресе. Текущая версия загружена через Cloudflare → Workers & Pages → `svoy-ritm` → Edit code: содержимое `worker.js` заменено содержимым `index.mjs`, затем нажата кнопка Deploy. Для этого проекта используется план Workers Free; платный домен не требуется.

Автоматическая публикация коммитов сейчас не подключена. После изменения кода нужно обновить репозиторий и повторно загрузить сборку в редактор Worker. Для публикации через официальный CLI предусмотрен `wrangler.json`: команда `npx wrangler@4.136.3 deploy` из корня репозитория. Для настройки автоматической публикации можно использовать [Cloudflare Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/).

В настройках Worker → Variables and Secrets задайте два **серверных секрета**:

- `SCHOOLS_SESSION_KEY`: один случайный 32-байтный ключ в base64. Генерация локально: `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"`.
- `SCHOOLS_PUPIL_ID`: число из адреса вашего дневника `/pupil/ЧИСЛО`.

Хост `lyceum.schools.by` задан в `wrangler.json`. Ключ и ID ученика не помещайте в код. Логин и пароль Schools.by вводятся на опубликованном сайте; пароль не сохраняется. Cookie сессии зашифрованы и привязаны к браузеру и домену. До настройки секретов интерфейс работает, а подключение дневника сообщает, что конфигурация не настроена.

## Изменение приложения

Распакуйте `source.zip`: внутри React/TypeScript, сервер, тесты и инструкции. Требуются Node.js 24 и pnpm 11.25.0. Установите зависимости (`pnpm install --no-frozen-lockfile`), выполните `pnpm test` и `pnpm build`. Скопируйте `dist/server/index.js` в `index.mjs` этого репозитория и обновите архив исходников. Затем создайте коммит и опубликуйте новую сборку в Cloudflare. Сборка содержит 39 прошедших тестов расчётов, импорта, перехода к неделе, проверки доступности и защиты сессий; запуск с реальной учётной записью Schools.by требует проверки владельцем.

## Перенос записей

На старом сайте нажмите «Скачать дневник», затем на новом — «Импорт резервной копии». Данные между адресами автоматически не переносятся. В Schools.by на новом адресе нужно войти заново. Проверка оценок выполняется при открытии сайта, возвращении на вкладку и каждые 15 минут, пока сайт открыт.

## Подготовленный сервер для Render

В репозитории есть `server.mjs`, `server.test.mjs`, `package.json` и `render.yaml` для запуска той же сборки в Node.js 24. Этот вариант подготовлен для проверки другого соединения с Schools.by; успешная работа на Render пока не подтверждена.

Для Web Service указаны Free, регион Frankfurt, команда сборки `node --check server.mjs`, команда запуска `node server.mjs`, проверка здоровья `/healthz`. Автопубликация выключена. Дополнительные библиотеки устанавливать не нужно. Проверка адаптера: `node --test server.test.mjs`.

Первый запуск возможен без ключа шифрования и ID ученика. Адрес `/health/schools` проверяет только две публичные страницы Schools.by и не отправляет пользовательские cookie или пароли. Результат кешируется на 30 секунд. До настройки секретов сам трекер работает, а подключение дневника сообщает об отсутствии конфигурации.

Только после успешной проверки соединения нужно добавить в Environment серверные секреты `SCHOOLS_SESSION_KEY` и `SCHOOLS_PUPIL_ID`; `SCHOOLS_HOST` уже задан как `lyceum.schools.by`. Render автоматически задаёт адрес сервиса через `RENDER_EXTERNAL_URL`, поэтому сессии привязаны к новому домену. Прежние серверные сессии между доменами не переносятся.

У [Render Free](https://render.com/docs/free) сервер засыпает после 15 минут без запросов; следующее открытие может занять около минуты. Платный тариф для этой проверки не требуется. Доступность Schools.by из Render нужно проверить отдельно до ввода учётных данных.

Код и сборка не содержат паролей, серверных ключей, личного ID ученика и истории браузера. Доступность Schools.by и сайта из конкретной сети нужно проверять после публикации. Действуют [бесплатные лимиты Cloudflare Workers](https://developers.cloudflare.com/workers/platform/limits/) и [Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/).
