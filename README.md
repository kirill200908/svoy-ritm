# Свой ритм

Личный трекер: десятки по математике и физике, другие десятки, задачи Codeforces и ejudge, контесты. Веса и ориентир редактируются; история и заметки сохраняются в браузере. Вкладка «Дневник» подключает Schools.by без аккаунта ChatGPT.

## Размещение

GitHub хранит готовую сборку `index.mjs` и полный архив исходников `source.zip`. Cloudflare Workers публикует интерфейс и API на одном адресе `svoy-ritm.<поддомен>.workers.dev`. В Cloudflare → Workers & Pages → Create application → Import a repository выберите этот репозиторий и основную ветку `main`. Папка проекта — корневая. Build command оставьте пустой: сборка уже подготовлена. Deploy command: `npx wrangler@4.136.3 deploy`. Для этого проекта используется план Workers Free; платный домен не требуется. Новые коммиты публикуются через встроенную интеграцию GitHub и Cloudflare Workers Builds.

В настройках Worker → Variables and Secrets задайте два **серверных секрета**:

- `SCHOOLS_SESSION_KEY`: один случайный 32-байтный ключ в base64. Генерация локально: `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"`.
- `SCHOOLS_PUPIL_ID`: число из адреса вашего дневника `/pupil/ЧИСЛО`.

Хост `lyceum.schools.by` задан в `wrangler.json`. Ключ и ID ученика не помещайте в код. Логин и пароль Schools.by вводятся на опубликованном сайте; пароль не сохраняется. Cookie сессии зашифрованы и привязаны к браузеру и домену. До настройки секретов интерфейс работает, а подключение дневника сообщает, что конфигурация не настроена.

## Изменение приложения

Распакуйте `source.zip`: внутри React/TypeScript, сервер, тесты и инструкции. Требуются Node.js 24 и pnpm 11.25.0. Установите зависимости (`pnpm install --no-frozen-lockfile`), выполните `pnpm test` и `pnpm build`. Скопируйте `dist/server/index.js` в `index.mjs` этого репозитория и обновите архив исходников. Затем создайте коммит. Сборка содержит 33 прошедших теста расчётов, импорта и защиты сессий; запуск с реальной учётной записью Schools.by требует проверки владельцем.

## Перенос записей

На старом сайте нажмите «Скачать дневник», затем на новом — «Импорт резервной копии». Данные между адресами автоматически не переносятся. В Schools.by на новом адресе нужно войти заново. Проверка оценок выполняется при открытии сайта, возвращении на вкладку и каждые 15 минут, пока сайт открыт.

Код и сборка не содержат паролей, серверных ключей, личного ID ученика и истории браузера. Доступность Schools.by и сайта из конкретной сети нужно проверять после публикации. Действуют [бесплатные лимиты Cloudflare Workers](https://developers.cloudflare.com/workers/platform/limits/) и [Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/).
